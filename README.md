## 🎮 ゲーム紹介

本作は、キューブを伸ばしたり縮めたりして道を作り、ゴールを目指す**パズルゲーム**です。<br>
> キューブの特性を活かし、ステージ内の鍵を集めて宝箱を開けましょう！

| 項目 | 内容 |
|---|---|
| ジャンル | 3D・パズルゲーム |
| プレイ人数 | 1人 |
| 操作方法 | マウスのみ |
| 制作イベント | Kenney Jam 2026 |

<br>

## 📏 テーマ「SCALE」

- 唯一使用できる道具、キューブの各面を引っ張ることで、それぞれの方向へ**自由に**伸ばしたり縮めたりできます。  
- 同じキューブでも、形や大きさを変えることで、**橋**、**足場**など、さまざまなものとして利用できます。  
> 届かない場所へ進むために、キューブの形を工夫して、各ステージのギミックを解いて行きましょう！

<br>

## ✨ Bonus Challenges

本作品では、Kenney Jam 2026の以下3つのBonus Challengesに挑戦しました。

| チャレンジ名 | 内容 |
|:---:|---|
| **No Text** | ゲーム内では文字を使用せず、見た目と操作だけで遊び方が伝わるように制作しました |
| **Mouse Only** | 移動、キューブの変形、カメラ操作など、すべての操作をマウスだけで行えます |
| **Symmetry** | ステージのビジュアルやキューブを使った仕掛けに、対称性を意識した要素を取り入れています |

<br>

## 🖱️ 操作方法

| 操作項目 | マウス操作 |
|---|---|
| キャラクターの移動 | 地面を左クリック |
| キューブを伸ばす・縮める | キューブの面を左クリックしたままドラッグ |
| カメラを回転する | 右クリックしたままドラッグ |

> キューブの面は、それぞれ別の方向へ動かすことができます
